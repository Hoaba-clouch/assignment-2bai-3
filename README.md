# Bao cao Phan tich SDLC va Luong TPS-MIS

## Bay giai doan SDLC

| Giai doan | Cong viec | Deliverable |
|---|---|---|
| Lap ke hoach | Pham vi tinh thu lao, stakeholder | Scope, feasibility |
| Phan tich | Quy tac 20.000d DELIVERED, thuong >50, DISPUTED | SRS, rules |
| Thiet ke | Luong TPS den MIS, schema | SDD, data model |
| Lap trinh | Ham tinh tien va thuong | Python source |
| Kiem thu | Test 0/50/51 va DISPUTED | Test plan, report |
| Trien khai | Cau hinh va huong dan | Deployment plan |
| Bao tri | Theo doi va cap nhat quy tac | Change log |

## Luong TPS den MIS

TPS ghi nhan don; trich xuat theo tuan; kiem tra du lieu; giu DISPUTED; chi tinh DELIVERED; tinh 20.000d moi don; tren 50 don cong 10%; tong hop MIS. Bo qua phan tich gay sai quy tac, bo qua kiem thu gay loi tinh tien va tranh chap.
